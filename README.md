# EightBool

Backend project built using Clean Architecture and .NET.

## Architecture

```text
Eight.API
│
├── Eight.Application
│
├── Eight.Domain
│
└── Eight.Infrastructure
```

## Project Layers

- API - HTTP endpoints and presentation layer
- Application - Business logic and use cases
- Domain - Entities, interfaces and business rules
- Infrastructure - Database access and external services

## Technologies

- .NET 8
- ASP.NET Core Web API
- Entity Framework Core
- Clean Architecture
